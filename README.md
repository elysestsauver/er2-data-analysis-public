# er2-data-analysis

Data-analysis code from the **ER2: Returning Results to Participants** project,
a randomized controlled trial conducted in Tanzania (Kagera and Dar es Salaam)
in collaboration with the University of Oregon and supported by the National
Science Foundation. The study explored how RCT participants prefer to receive
results from studies they take part in, using a discrete choice experiment
(DCE).

This is the **public version** of the codebase as of mid-July 2025. The R/
Stata scripts, scenario-generation tooling, and image assets are included;
the underlying respondent-level datasets are not. See `Datasets/README.md`
and `Data Analysis/Codebook/README.md` for the schema each script expects.

## What's in each part

### `Data Analysis/`
The main analysis pipeline. `Data Cleaning and Analysis Script.Rmd` cleans
the respondent-level survey data, joins it with the scenario/assignment
lookups, and runs the DCE regression analysis. The older `ER2 Kagera Data
Cleaning and Analysis 1.Rmd` is the original Kagera-only version; the
consolidated script supersedes it. Generated plots are committed for
reference.

The `Codebook/` subfolder holds the variable dictionary that explains each
column in the analysis datasets, plus working cleaning notes.

### `Datasets/DarDataOutput/`
SurveyCTO-style import workflow for the three Dar es Salaam wards
(Mbagala, Tandika, Temeke). Each ward has a pair of `import_*.do` scripts
generated by SurveyCTO that load the raw CSV exports into Stata format.
`Data Preparations.do` then merges the per-ward `.dta` files into combined
`RR-RCT.dta` and `RR-RCT-DCE.dta` outputs in `raw/`. Paths in the import
scripts are relative — drop the matching CSVs into each ward folder and the
scripts will run from there.

### `Generating Scenario Image Scripts and Assets/`
Tooling for generating the DCE choice-set images each respondent saw.
`ER2 Script for Generating the Scenario Pairs and Images.Rmd` was used for
the Kagera and Dar sites; `ImageGenerationforKenya.Rmd` regenerates images
with Kenyan-shilling compensation tiles for an additional Kenya site
(Kenya analysis itself is not in this snapshot of the codebase). The script
uses the `jpeg` R package to stitch attribute tiles together — note that
`jpeg` will only accept `.jpeg` extensions, not `.jpg`. The `Assets/`
folder contains the input tiles (currency images, participant/community/
policymaker illustrations, headings); outputs follow the pattern
`stitched_output_###.jpeg`.

The `xDEPRECATED First attempt at script for creating the scenario pairs.Rmd`
script is kept for historical reference; the bundle-design experiments it
contains were not used in the final study.

## Running the analysis

You'll need a recent R installation plus Stata (for the `.do` import
workflow on the Dar data — optional if you only want to work with the CSV
exports the analysis script can produce).

R packages used across the scripts:

```r
install.packages(c(
  "tidyverse", "dplyr", "tidyr", "stringr",
  "ggplot2", "ggthemr", "scales",
  "cbcTools",
  "DT", "gt", "kableExtra",
  "janitor", "openxlsx", "pacman", "jpeg"
))
```

Steps:

1. Open `er2-data-analysis.Rproj` in RStudio.
2. Place the expected datasets in `Datasets/` (see `Datasets/README.md` for
   filenames and schemas).
3. Knit the relevant `.Rmd` in `Data Analysis/`.

For the Dar Stata workflow, drop each ward's raw SurveyCTO export into
`Datasets/DarDataOutput/{Mbagala,Tandika,Temeke}/`, then run the
`import_*.do` scripts followed by `Data Preparations.do`.

## A note on data

The respondent-level datasets are not included in this repository. If you'd
like to reproduce the analysis with your own data, the expected schemas are
documented in `Datasets/README.md` and `Data Analysis/Codebook/README.md`.
